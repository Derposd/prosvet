## Зачем

«Телеграм не работает» может означать совершенно разные вещи. Провайдер может удалить имя из DNS,
отрезать IP-адрес сервера, оборвать TLS-рукопожатие, увидев имя сайта (DPI по SNI), «заморозить»
любое соединение с зарубежным хостингом после первых ~16 КБ, фильтровать QUIC или переключить
мобильный интернет в режим *белых списков*, где работают только разрешённые отечественные сервисы.

У каждого случая своё объяснение, и картина меняется от недели к неделе (см.
[исследование](docs/research.md)). Prosvet проводит для каждого сервиса набор дифференциальных тестов
и простым языком объясняет, какой метод применяется, насколько он в этом уверен и почему.

- **Один статический бинарник** для Windows, Linux, macOS и роутеров OpenWrt. Без зависимостей и регистрации.
- **Только измерения.** Никаких прокси, туннелей и VPN — Prosvet объясняет, а не перенаправляет трафик.
- **Приватность по умолчанию.** Всё выполняется локально; ничего никуда не отправляется, пока вы сами не запустите `prosvet submit`.
- **Открытые данные.** Анонимные результаты собираются в [публичную карту](https://derposd.github.io/prosvet/)
  «сервис × провайдер», которую строит GitHub Actions — без сервера и трекеров.

## Быстрый старт

```bash
# 1. скачайте бинарник для своей ОС: https://github.com/Derposd/prosvet/releases/latest
# 2. запустите интерактивный TUI
prosvet
# 3. или разовую проверку с отчётом
prosvet scan && prosvet report --format html -o report.html
```

Хотите увидеть все типы вердиктов, не трогая реальную сеть? `prosvet demo` проверяет симулированную
цензурированную сеть, запущенную на вашем компьютере.

## Возможности

| | |
|---|---|
| **DNS** | Системный резолвер vs национальная DNS (НСДИ) vs DNS-over-HTTPS; находит удалённые записи, заглушки и непубличные адреса, подмену, блокировку DoH/DoT и прозрачный перехват DNS |
| **TCP / IP** | Подключение к каждому адресу; drop или reject; отличает «заблокирован узел CDN» от подмены DNS |
| **TLS / SNI** | Рукопожатие с настоящим именем, **без SNI** и со **случайным SNI** — дифференциальный тест, отделяющий DPI по имени от блокировки по IP и от общего сброса TLS |
| **Сертификаты** | Отмечает сертификаты государственного УЦ РФ на зарубежных сайтах (MITM); не путает их с частными УЦ (например, у Signal) |
| **HTTP** | Отпечатки страниц-заглушек российских провайдеров; обрывы посреди передачи |
| **Замедление** | Детект «заморозки 16–20 КБ» по байтам **на уровне TCP** и ограничения скорости относительно отечественного эталона |
| **QUIC / ECH** | QUIC v1/v2 с настоящим и случайным SNI (новый UDP-порт на каждую попытку), Encrypted Client Hello |
| **Белые списки** | `prosvet whitelist` — доступны ли только разрешённые отечественные сервисы? На уровне DNS, IP или DPI? |
| **Надёжность** | Каждый тест 3 раза, итог по большинству; уровни уверенности; доказательства для каждого вывода |
| **Сеть** | ASN, провайдер, регион (субъект РФ), мобильный или проводной, предупреждение о VPN/прокси — ваш IP нигде не сохраняется |
| **Интерфейсы** | TUI (bubbletea), обычный CLI, локальный веб-дашборд (`prosvet serve`, только 127.0.0.1) |
| **Отчёты** | Терминал, JSON, Markdown, самодостаточный HTML (без скриптов) |
| **Языки** | Русский и английский, автоопределение; все тексты — в [`locales/`](locales) |
| **Цели** | 60+ сервисов в редактируемых YAML ([`targets/`](targets)), для каждого ожидания — источник |

Каждый вердикт сопровождается объяснением и доказательствами, например: *«TLS-рукопожатие с настоящим
именем сайта не удалось: reset. Наблюдалось в 3 из 3 попыток. Тот же сервер ответил на рукопожатие
с вариантом SNI „random“»*.

## Как это работает

Для каждого адреса каждого сервиса:

1. **DNS** — системный резолвер ×3, национальная DNS (НСДИ) и DoH с откатом (Cloudflare → Quad9 → AdGuard → Google).
2. **TCP + TLS** ×3 с настоящим SNI; HTTP-запрос идёт по тому же соединению и читает до 64 КБ с детектом остановки.
3. Если рукопожатие не прошло — рукопожатия **без SNI** и **со случайным SNI** ×3 к тому же IP.
4. **Замедление**: большой файл с того же хостинга, байты считаются на уровне TCP; скорость сравнивается с отечественным зеркалом.
5. **QUIC** (сначала случайный SNI — отфильтрованный поток «глушится» на минуты) и **ECH**, где они указаны.
6. **Классификатор** объединяет сигналы ([правила](docs/research.md#7-методология-prosvet-вывод-из-ресёрча)).
   Поле `expect` из открытых источников показывается рядом с результатом, но никогда не влияет на вердикт.

| Вердикт | Сигнатура |
|---|---|
| Подмена DNS | системный резолвер: NXDOMAIN / заглушка / непубличный адрес, а DoH возвращает рабочий адрес |
| Блокировка по IP | TCP не проходит ни к одному адресу, при этом контрольные хосты доступны |
| DPI по SNI | TCP проходит; TLS с настоящим именем падает; без SNI или со случайным SNI — проходит |
| Сброс TLS | рукопожатие рвётся независимо от имени |
| Замедление: заморозка | передача встаёт после ~12–36 КБ на уровне TCP, без RST |
| Замедление: скорость | < 25 % отечественного эталона и < 1 Мбит/с |
| Перехват TLS | зарубежный сайт с сертификатом от государственного УЦ РФ |
| QUIC по SNI | QUIC с настоящим именем без ответа, со случайным — отвечает |

## Установка

| Способ | Команда |
|---|---|
| Бинарник | скачать из [последнего релиза](https://github.com/Derposd/prosvet/releases/latest), сверить `checksums.txt`, запустить |
| Docker | `docker run --rm -it --network host ghcr.io/derposd/prosvet` |
| Debian/Ubuntu, Fedora, Alpine | пакеты `.deb`, `.rpm`, `.apk` на странице Releases |
| Go | `go install github.com/Derposd/prosvet/cmd/prosvet@latest` |
| Роутер OpenWrt | скопировать `prosvet_*_linux_mipsle_softfloat` (или `mips_softfloat`, `armv7`, `arm64`) в `/tmp`, `chmod +x`, запустить `./prosvet scan --yes` |

Пакеты для Scoop, winget и Homebrew — в планах (см. [дорожную карту](ROADMAP.md)).

## Команды

| Команда | Что делает |
|---|---|
| `prosvet` | интерактивный TUI |
| `prosvet scan` | проверка категорий по умолчанию (`--target telegram`, `--category messengers`, `--all` — с категориями по согласию) |
| `prosvet whitelist` | проверка режима белых списков |
| `prosvet report --format html\|md\|json` | показать последний отчёт (`-o файл`) |
| `prosvet serve` | локальный веб-дашборд на `127.0.0.1:8787` (`--open`) |
| `prosvet submit` | подготовить анонимный файл результатов для публичной карты |
| `prosvet targets` | список сервисов и категорий |
| `prosvet demo` | проверка симулированной цензурированной сети (`--tui`) |

Полезные флаги: `--lang ru|en`, `--brief`, `--verbose`, `--timeout-scale 2` для медленного мобильного
интернета, `--targets-dir ./my-targets` для своих списков, `--asn`/`--region`/`--conn`, чтобы не
определять сеть через интернет.

## Публичная карта

[**derposd.github.io/prosvet**](https://derposd.github.io/prosvet/) показывает последний статус
каждого сервиса по провайдерам, регионам и типам подключения, график по дням и историю того, когда
началась блокировка. Это статический сайт, который GitHub Actions пересобирает из [`results/`](results).

Как добавить данные: `prosvet scan`, `prosvet submit`, затем pull request с файлом или вставка его
содержимого в [форму issue](https://github.com/Derposd/prosvet/issues/new?template=submit-results.yml).

## Приватность

- Никакой телеметрии, аналитики и проверки обновлений. Все измерения — на вашем компьютере.
- Публичный IP используется только в памяти, чтобы узнать ASN и регион (RIPEstat), и **нигде не
  сохраняется**; с `--offline-netinfo --asn N` не используется даже так.
- Последний отчёт хранится в кэш-каталоге пользователя; `prosvet submit` показывает **ровно** то, что
  будет опубликовано (без IP, времени суток и данных устройства), и записывает файл — публиковать или нет, решаете вы.
- Пробы игнорируют `HTTP(S)_PROXY` и предупреждают о включённом VPN: иначе результат описывал бы выходной узел VPN, а не вашего провайдера.

Подробнее: [PRIVACY.md](PRIVACY.md).

## Вопросы и ответы

**Это VPN или средство доступа к заблокированному?** Нет. В Prosvet нет кода прокси, туннелей или VPN.
Он измеряет и объясняет — как градусник.

**Законно ли запускать это в России?** Проверка того, открывается ли сайт, — обычная диагностика сети.
Prosvet не получает заблокированный контент дальше рукопожатия и первых байт публичной страницы.
Категория `media` включается только по согласию, потому что провайдер видит эти подключения.

**Зачем каждый тест повторяется трижды?** Оборудование фильтрации перегружено и работает непоследовательно;
одиночные замеры дают ложные срабатывания. Итог определяется большинством, а уверенность понижается,
если попытки расходятся.

**Почему не OONI Probe?** OONI — отличный проект, он вдохновил Prosvet. Prosvet закрывает то, чего нет в
веб-тесте OONI за один прогон: разделение SNI и IP, заморозку 16–20 КБ, режим белых списков, перехват
DNS, понятные вердикты — и работает без бэкенда. См. [сравнение](docs/research.md#6-существующие-инструменты-и-пробелы).

**Работает ли вне России?** Да — пробы и классификатор универсальны; российскими являются списки целей
по умолчанию и часть отпечатков. Добавьте свои `targets/*.yaml`.

**Можно ли запустить на роутере?** Да: статические бинарники для OpenWrt (mips/mipsle softfloat,
armv7, arm64) сжаты UPX. Измерение с роутера показывает, что получает вся квартира.
